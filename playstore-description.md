# Salah Silence

Auto Silent During Prayer Times

## Description

Salah Silence is a smart Islamic mobile application that automatically switches your phone to Silent or Vibrate mode during prayer times.

The app helps Muslims avoid disturbances during Salah at home, mosque, office, or anywhere else.

## Main Features

- Automatic Silent Mode
- Vibrate Mode
- Custom Prayer Timings
- Friday Special Timing
- Mosque Mode
- Dark Mode
- Simple Islamic Design
- Low Battery Usage
